# PERC vs Other Coaching Institutes — Comparison

## What Makes PERC Different

PERC — Personalized Education Research Centre — is positioned as a small-batch, high-quality, personalized coaching institute in Begur, Bengaluru. Unlike large national chains or mass coaching centers, PERC focuses on individual student growth.

## Key Differentiators

| Feature | PERC | Large Coaching Chains |
|---|---|---|
| Batch size | 15-20 students (capped) | 50-200+ students |
| Individual attention | High (small batches) | Limited |
| Personalized study plans | Yes | Rarely |
| Parent communication | Monthly PTMs, regular WhatsApp/phone updates | Minimal or periodic |
| Demo class | Free demo before enrollment | Varies |
| Diagnostic assessment | Yes, before batch allocation | Rarely |
| Doubt-clearing sessions | After every class + individual sessions | Group sessions only |
| Faculty access | Direct, personal | Limited |
| Location | Local, community-centered (Begur) | Multiple large centers |
| Teaching style | Concept-based + personalized | Standardized, syllabus-driven |
